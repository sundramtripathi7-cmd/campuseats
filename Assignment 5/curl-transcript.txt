CampusEats Assignment 5 — curl -v transcript
===============================================

Environment:
  Catalog Service: http://127.0.0.1:5000
  Authorization: Bearer campuseats-demo-token
  Note: Date/Server/Content-Length values can vary by Flask/Werkzeug version.
  The ETags below are deterministic for the shown menu-item representations.

==================================================
1. Successful Create — 201 + Location
==================================================

COMMAND:
curl.exe -v -X POST "http://127.0.0.1:5000/menu-items" ^
  -H "Authorization: Bearer campuseats-demo-token" ^
  -H "Accept: application/json" ^
  -H "Content-Type: application/json" ^
  -H "Idempotency-Key: a5-create-001" ^
  --data-binary "@a5-create.json"

HTTP RESPONSE:
HTTP/1.1 201 CREATED
Content-Type: application/json
Content-Length: 105
Location: /menu-items/1
ETag: "862e3523c09c7a32"
Cache-Control: no-store
X-RateLimit-Limit: 20
X-RateLimit-Remaining: 19
X-Content-Type-Options: nosniff
Strict-Transport-Security: max-age=31536000; includeSubDomains
Access-Control-Allow-Origin: http://localhost:3000

{

  "price": 80.0
